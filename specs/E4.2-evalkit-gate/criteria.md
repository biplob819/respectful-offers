# E4.2 acceptance criteria

**EVK-03** — CI gates with `evalkit gate` (evalkit-harness ≥ 0.3.0, an optional extra, never a runtime requirement: a clean `pip install respectful-offers` imports and runs `offers metrics` without EvalKit). On the committed files it exits 0 with both age-band disparity warnings and `simulated: true`. On every planted defect from `tests/evalkit/test_gate.py`, `evalkit gate` and `scripts/gate.py` agree on the exit code and on each gate row's status. EvalKit's metrics-1 loader and `validate_metrics1` agree, accept or refuse, on the committed file and every planted validator defect.
**EVK-04** — Offline `contract` tests import only EvalKit's public API, load the committed metrics with EvalKit's loader and gate them, and run under the canary's command (`uv sync --frozen --extra evalkit`, then `pytest <files> -m "not live"`) with no network or keys. An `ast` test fails on any non-public `evalkit` import. The request to flip EvalKit's registry row to `tests=auto` is sent to EvalKit's build and recorded in `docs/decisions.md`. Once EvalKit records the flip, its canary run on this repo is green.
