# N1.5 KKBox acquisition and licence

Download the real KKBox files with the owner's Kaggle credentials, verify them, record the real facts (checksums, row counts, date ranges) in the manifest and the data card, read the competition rules, quote the governing terms in the data card and record the owner's publishing ruling (OWNER D-46). Depends on N1.2 (the download and verify commands). No new code: the node proves the real files match what the pipeline expects and that what is published is allowed.

Out of scope: running the pipeline on the real data (A2.8).
