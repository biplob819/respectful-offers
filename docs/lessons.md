# Lessons

Numbered L-n. Each lesson names the failure, the rule it produced, and where that rule is enforced. L-1 to L-12 are carried from EvalKit (`~/EvalKit/docs/lessons.md`, Tech Spec §11.8) so its verifier findings start here as rules.

| ID | Lesson | Rule | Enforced by |
| --- | --- | --- | --- |
| L-1 | A gate that has never failed is a gate nobody has checked (EvalKit L-1, L-4) | Every gate ships a `--self-test` that plants a defect and requires its identity in the output | `node_converge.py --self-test`, `tests/harness/` |
| L-2 | A proof can name a test that is only a comment, a string, a prefix or skipped (EvalKit L-2) | Proofs resolve through `ast` to a real, unskipped `def test_*` under `tests/`; `logical` is never n/a | `node_converge.proof_problems` |
| L-3 | Frozen pydantic models are shallow and accept infinity (EvalKit L-8, L-9) | Sequences are tuples, mappings frozen, `allow_inf_nan=False` everywhere | N1.1 schema tests |
| L-4 | A contract test that loops over `__all__` can never find a missing export (EvalKit L-10) | Contract tests and the respect auditor compare against an independent source | N1.1 contract tests, `policy/audit.py` |
| L-5 | A NaN or negative money value silently switched a spend cap off (EvalKit L-12) | Every probability, price, cost and budget is checked finite and in range; a bad value is an error | Pacer and simulator validation |
| L-6 | Docs stated things in the present tense that were not yet true (EvalKit L-16) | Docs say what is true now and name the node that will make the rest true | Data card and README tests |
| L-7 | Missing scores defaulted to 0 and statistics tests used symmetric two-group fixtures (EvalKit L-25, L-26) | Never default a missing value; pin statistics with asymmetric hand-computed cases and at least three groups | A2.6, A2.7 tests |
| L-8 | Float sums differed across Python versions (EvalKit L-27) | `math.fsum` for every float total that reaches an output | A2.7 |
| L-9 | A guard that matched the forbidden thing missed variants (EvalKit L-35) | Guard by allow-list, never by matching what is forbidden | Feature allow-list (D-9) |
| L-10 | Resampling at the wrong level biased a statistic; infrastructure failures were scored as outcomes (EvalKit L-36) | Bootstrap at the level where the statistic is defined; failures are exclusions, never outcomes | A2.6, A2.7 |
| L-11 | Every unit test passed while the real headline was wrong (EvalKit L-37, L-38) | Before trusting a headline, read real decisions end to end and confirm each failure reason | A2.7 first real run |
| L-12 | Release checks grepped a workflow instead of running it (EvalKit L-40) | A test of a doc or workflow executes what it describes | B2.3 docs tests |
| L-13 | W0.1 verifier: the data scan let real Kaggle archive names (`members_v3.csv.7z`), gzip/zip/sqlite/UTF-16 member rows and ids inside URL paths through; gate self-tests re-ran their own commands instead of calling the gate functions, so a gate replaced by `return PASS` survived; CI tests accepted write permissions and a missing step | On a public repo, scan by allow-list: refuse archives, spreadsheets, data-file types and unrecognised binaries outright; a self-test must call the real gate function on a planted context and require the defect's identity; a workflow test checks exact permissions and every required step | `data_scan.self_test`, `test_real_kaggle_archive_names_are_refused`, `test_archives_and_data_files_are_refused_whatever_they_hold`, `node_converge.self_test`, `test_workflows_grant_least_privilege` |
| L-14 | W0.1 verifier round 2: pandas `to_json` writes `/` as `\/`, hiding about half of KKBox ids from the scan; percent-encoded, HTML-entity and UTF-32 ids also slipped through; PDFs were trusted as binaries; the publish-scan wiring and `gate_records` could be replaced by PASS unnoticed | Normalise text (JSON escapes, percent-encoding, entities, every Unicode BOM) before matching a forbidden pattern; a PDF ships only beside the text source it was built from, and that source is scanned; a self-test exercises each wiring with an input only that wiring can catch | `test_pandas_json_with_escaped_slashes_is_caught`, `test_percent_encoded_html_entity_and_utf32_ids_are_caught`, `test_a_pdf_needs_its_scanned_text_source`, `node_converge.self_test` (ignored `site/` file, `gate_records`) |
| L-15 | First CI run: the publish scan labelled files with `str(relative_path)`, which is `assets\\cube.json` on Windows, so a self-test that looked for `assets/cube.json` failed only there | Every path that reaches a message, label or comparison is written with `.as_posix()`; read the Windows jobs before calling a node done (EvalKit L-20, L-32) | `test_labels_use_forward_slashes_on_every_os` on windows-latest |
