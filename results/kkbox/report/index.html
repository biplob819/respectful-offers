# real KKBox runs; every real evaluation refuses a file whose sha256 is not in docs/prereg.md
# (D-3). Running on your own data? These are only starting values: set what you believe, then
# `offers prereg --scope real` before any real evaluation.

# These values are assumptions, not measurements: KKBox data holds no offers. They are chosen
# to be plausible and are bracketed by three variants, and every report quotes all three.
#   risk_bands      low < 5% churn risk <= medium < 15% <= high; R2's threshold is 15%. Base
#                   churn is about 6%, so "high" means two to three times the base rate
#                   (about 13% of members on the synthetic fixture).
#   segment_mix     riskier and declining-listening cells hold more persuadables and lost
#                   causes; sleeping dogs (offers remind them to leave) are 10-15% everywhere.
#   acceptance      about half of persuadables take a discount; sure things take it too (deadweight).
#   exposure_effect persuadables gain 2-4 points of renewal from being shown an offer; sleeping
#                   dogs lose 4-6 points when shown a commercial offer, even if they decline.
#   acceptance_effect: a persuadable who engages with a content nudge gains 12 points.
#   discount_1m     half price for one month; plan_change: the cheaper plan (99/149 = 0.67).
#   conservative    acceptance x0.7, persuadable effects x0.5, sleeping-dog harm x1.5,
#                   5 points of mix share move from persuadables to sleeping dogs (segments
#                   come from one shared uniform per member, so some members move by more
#                   than one segment between variants; only the shares are as stated).
#   plan_change     offered once, from the full plan; nudges cost nothing (not modelled).
#   optimistic      acceptance x1.25, persuadable effects x1.5, sleeping-dog harm x0.5,
